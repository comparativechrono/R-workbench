# R workbench

A workbench in the browser for the course's R practicals: R's own console, an RStudio-style IDE, Jupyter-style notebooks, R Markdown, R Notebooks and Quarto documents, a terminal with `Rscript`, files and an AI assistant – with the instructions of a practical beside them. R runs in the browser (webR): nothing to install.

The workbench itself, and its README, come with the first pull request.
